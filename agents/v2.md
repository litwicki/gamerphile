## User Profile

Create a /user profile page that is accessible only if a user is logged in. As a result, remove Theme, Region, and Ultrawide options from the avatar menu in the main AppBar.

This page should be designed with vertical tabs (with icon) for the following sub-sections:

1. Settings
2. Characters
3. LFG
4. Integrations

### Settings

Each of the following options will be a button with toggle (on/off), text, and description.

1. Hide all of my characters (off by default)
2. Ultrawide Mode

Each of these settings will be selectable dropdowns

1. Region
2. Default Realm (list of all realms in the selected region)
3. Theme

### Characters

By default a user will see a table listing all of their characters. Each character name will be class colored, and display the name, level, realm, m+ rating, raid progress. Clicking on a row will open a full screen dialog form (we will update this later).

### LFG

The LFG section is where users will indicate if they are "LFG" or not. This is ambiguous on purpose to indicate they are looking-for-guild, or looking-for-group (M+). There will be two separate buttons with toggle, description and text. One for Raid, and one for M+. The user can toggle each independently. If toggled on, the user is shown a form to select which of their characters they want to participate in for that activity. This will be displayed as a multi-select dropdown of their characters shown like this: 

Raiding: {characterName} ({level}) {raidProgression}
M+: {characterName} ({level}) {mplusRating}

In both cases the character name will be class colored. If at least one selection is made, the next options shown to the user are which days of the week, and what range of hours they are available. This will be presented to the user as a buttongroup of days-of-the-week, and below that, for each day selected, a row with prompt for startTime, and endTime (and timezone).
